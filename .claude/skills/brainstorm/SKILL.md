# Brainstorm

Generate expansive, concrete ideas on any SCAiL topic. This skill gives you a structured creative partner.

## Usage

```
/brainstorm [topic]
```

Examples:
- `/brainstorm grant strategy`
- `/brainstorm pilot session format`
- `/brainstorm SC trip meeting agenda`
- `/brainstorm public site improvements`

## What this does

When invoked, I will:
1. **Reframe** the topic to make sure we're asking the right question
2. **Generate 8–12 concrete ideas** across different angles (practical, creative, bold, community-focused)
3. **Rank top 3** by impact × effort
4. **Identify the one thing** to do first
5. **Flag risks or blind spots** worth considering

## Approach

- Prioritize ideas specific to South Carolina / community context
- Think across all three phases: Nonprofit → Incubator → Fund
- Consider Joshua's communications background as an asset
- Never generic — every idea should be actionable within 30 days or 6 months

## Output format

```
🔄 REFRAME
[better version of the question]

💡 IDEAS
1. [Concrete idea — who, what, where, when]
2. ...
...

🏆 TOP 3 (impact × effort)
1. [Best idea]
2. [Second best]
3. [Third]

⚡ DO THIS FIRST
[Single most actionable item]

⚠️ BLIND SPOTS
[What we might be missing]
```
