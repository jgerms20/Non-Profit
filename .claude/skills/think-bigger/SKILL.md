# Think Bigger — Strategic Reframe

Forces a strategic zoom-out from the current task to the bigger picture.

## Usage

```
/think-bigger
/think-bigger [specific area to reframe]
```

## What this does

1. **Diagnose current mode** — are we iterating or building?
2. **10x question** — what would make SCAiL 10x more impactful vs. 10% better?
3. **Unfair advantages** — what can SCAiL do that nobody else can?
4. **Phase 1 → 2 → 3 bridge** — what does the current work unlock downstream?
5. **The overlooked thing** — what important thing is getting zero attention?
6. **One bold move** — what's the highest-leverage action in the next 30 days?

## Output format

```
🔭 CURRENT MODE
[iteration / execution / strategy / stuck]

⚡ THE 10X QUESTION
[What would make SCAiL 10x more impactful, not 10% better?]

🎯 UNFAIR ADVANTAGES
[What can SCAiL uniquely do that others can't?]

🔗 PHASE BRIDGE
[How does today's work set up Phase 2 / Phase 3?]

👁️ WHAT'S BEING OVERLOOKED
[The important thing getting zero attention]

🚀 BOLD MOVE
[Highest-leverage action in the next 30 days]
```

## Context always relevant to SCAiL

- Joshua's communications / advertising background = storytelling superpower
- SC is underserved but has real institutions (USC, Clemson, MUSC, legislature)
- Phase 1 → Phase 2 → Phase 3 flywheel must be kept in mind at all times
- Grants are fuel, not the mission — community impact is the mission
- 46 counties = scope ambition, but start in the Midlands and grow out
