# Media

Drop real SCAiL photos here (e.g. `irmo-class.jpg`), then set the matching
`src` field in `src/data/mediaGallery.json` — for example:

    "src": "/media/irmo-class.jpg"

Until a photo is added, each gallery slot renders as a branded gradient
placeholder with its caption. The Content Engine's "Featured Media Rotation"
loop keeps the homepage gallery order fresh.
